我的个人空间

一个蓝白配色、圆角卡片风格的中文个人网站，用来介绍自己、展示服务内容、呈现作品并提供公开联系方式。

个人介绍 服务展示 作品展示 联系方式 响应式布局

Background

项目背景

这是我学习使用 Codex、GitHub、HTML、CSS 和 JavaScript 后完成的第一个公开网页项目。我通过实际操作，学习了从创建代码仓库、修改网页内容，到使用 GitHub Pages 发布网站的完整流程。

Status

项目状态

持续更新中

Features

主要功能

  • 中文个人介绍
  • 服务内容展示
  • 个人作品展示
  • 微信、邮箱和 GitHub 联系方式
  • 电脑端与手机端响应式布局
  • 浏览器标签名称和网站小图标
  • 页面导航与平滑滚动
  • GitHub Pages 公开发布

Tech Stack

使用技术

HTML：负责网页内容和结构

CSS：负责颜色、排版、卡片和响应式布局

JavaScript：负责按钮和页面交互

Codex：辅助创建、修改和检查代码

GitHub：保存代码和管理修改历史

GitHub Pages：将网站发布为公开网址

Process

制作过程

  1. 创建 GitHub 代码仓库。
  2. 连接 Codex 与 GitHub。
  3. 使用 Codex 创建网页基础文件。
  4. 修改标题、文字、头像和联系方式。
  5. 添加作品展示区域。
  6. 优化电脑端和手机端布局。
  7. 通过 Pull Request 检查并合并代码。
  8. 使用 GitHub Pages 发布网站。

Learning

学习收获

通过这个项目，我初步了解了网页文件的组成，学会了使用 Codex 修改代码、使用 GitHub 管理版本，以及将网页发布到互联网。我也学会了检查代码差异、测试手机端显示和安全恢复历史版本。
