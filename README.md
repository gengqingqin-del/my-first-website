# 我的第一个网页

这是一个从零创建的中文静态网页项目，使用蓝色和白色配色，包含首页介绍、关于我、服务内容、联系方式和页脚，并支持电脑与手机屏幕自适应浏览。

## 文件说明

- `index.html`：网页主体结构，包含各个内容区域和“了解更多”按钮。
- `style.css`：网页样式文件，负责蓝白配色、布局、卡片、按钮和响应式效果。
- `script.js`：网页交互脚本，点击“了解更多”按钮后平滑滚动到“关于我”区域。

## 使用方法

1. 下载或克隆本仓库。
2. 在项目根目录中找到 `index.html`。
3. 使用浏览器直接打开 `index.html` 即可查看网页。

无需安装任何依赖，也不需要使用复杂框架。

网页已通过 GitHub Pages 发布。
